promt : เลย์เอาต์:
- Sidebar ด้านซ้ายเต็มความสูง พื้นหลังสีน้ำเงินเข้ม มีโลโก้ ชื่อระบบ และเมนู:
  หน้าหลัก, ข้อมูลนักเรียน, แผนการเรียน, รายวิชา, ผลการเรียน, กิจกรรม/โครงการ, แนะแนวอาชีพ, เอกสารประกอบ, แจ้งเตือน, ตั้งค่า
- Topbar ด้านบน มีชื่อหน้า “หน้าหลัก”, ข้อความต้อนรับผู้ใช้, ไอคอนแจ้งเตือน, ไอคอนข้อความ, รูปโปรไฟล์
- เนื้อหาหลักเป็น dashboard แบบ 2 คอลัมน์

คอลัมน์ซ้าย:
1. การ์ดสรุป 4 ใบ:
   - หน่วยกิตรวม 42
   - หน่วยกิตที่เรียนแล้ว 28
   - หน่วยกิตที่เหลือ 14
   - เกรดเฉลี่ยสะสม 3.45
2. การ์ดความก้าวหน้าตามกลุ่มสาระ:
   - donut chart แสดง 66.67%
   - progress bar สำหรับ คณิตศาสตร์, วิทยาศาสตร์, ภาษาอังกฤษ, วิศวกรรมและเทคโนโลยี, สังคมศึกษา
3. ส่วนแนะนำสำหรับคุณ:
   - พัฒนาทักษะเพิ่มเติม
   - แนะแนวอาชีพ
   - โครงการ/กิจกรรม
4. แถบเครื่องมือด่วน:
   - คำนวณเกรด
   - เช็คหน่วยกิต
   - แผนที่เรียน
   - ดาวน์โหลดเอกสาร
   - ขอคำแนะนำ

คอลัมน์ขวา:
5. การ์ดแผนการเรียนของคุณ:
   - แสดงระดับชั้น ม.4 ม.5 ม.6 แบบ timeline
   - สถานะปัจจุบัน
   - ชื่อแผน “เตรียมวิศวกรรมศาสตร์”
   - ปุ่ม “ดูรายละเอียดแผนการเรียน”
6. รายวิชาที่ต้องเรียนในภาคเรียนนี้:
   - แสดงรายการรหัสวิชา ชื่อวิชา และหน่วยกิต
7. ปฏิทินการศึกษา:
   - แสดงวันสำคัญและกิจกรรม

สไตล์:
- ใช้ cards สีขาว มุมโค้ง มี shadow เบา
- sidebar active menu เป็นสีน้ำเงินสว่าง
- ใช้ไอคอนแบบ outline
- spacing เยอะ อ่านง่าย
- responsive สำหรับ desktop/mobile
- ข้อมูลทั้งหมดเป็นภาษาไทย
- UI ต้องดูเหมือนพร้อมใช้งานจริง และใกล้เคียงภาพตัวอย่างมาก
